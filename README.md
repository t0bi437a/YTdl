# YTdl

Android-приложение для скачивания видео с YouTube: по ссылке, по названию или по
автору, с выбором качества, очередью загрузок и кнопкой в меню «Поделиться».

## Возможности

- **Поиск** по названию видео или по имени канала; открытие канала и просмотр его роликов.
- **Скачивание по ссылке** — любой формат: `watch?v=`, `youtu.be/`, `/shorts/`, `/live/`,
  `music.youtube.com`, а также текст, в который вставлена ссылка.
- **Выбор качества** — от 144p до 2160p (4K), отдельно видео и «только звук».
  Показываются кодек, контейнер, fps и размер файла.
- **Очередь загрузок** — можно выделить несколько видео сразу (долгое нажатие),
  задать одно качество для всех и поставить их в очередь. Очередь переставляется
  стрелками, есть «остановить все» / «продолжить все», от 1 до 5 одновременных загрузок.
- **Кнопка в меню «Поделиться»** — из приложения YouTube: Поделиться → YTdl.
  Открывается только выбор качества поверх YouTube. В настройках можно включить
  «Мгновенная загрузка», тогда качество не спрашивается вообще.
- **Настройки**: качество по умолчанию, MP4/H.264 или WebM/VP9, только Wi-Fi,
  папка сохранения (по умолчанию `Movies/YTdl` и `Music/YTdl`, либо любая своя через
  системный выбор папки), шаблон имени файла, субтитры, обложка, тема и динамические цвета.
- **Докачка** — загрузка продолжается с того места, где остановилась; если ссылка
  на поток протухла, приложение само получает новую.

## Как это работает

**Скачивание** полностью построено на [yt-dlp](https://github.com/yt-dlp/yt-dlp) —
том самом, что и на ПК. Внутрь APK через библиотеку
[youtubedl-android](https://github.com/yausername/youtubedl-android) упакованы
интерпретатор Python, сам yt-dlp и ffmpeg; всё это работает прямо на телефоне.
yt-dlp сам разбирается со всей сложной частью — токенами, подписями, выбором
форматов, докачкой фрагментов и склейкой дорожек через ffmpeg. Именно поэтому
загрузка стабильна и не ломается, когда YouTube что-то меняет. При запуске
приложение в фоне обновляет бинарник yt-dlp до свежего, так что новые изменения
YouTube подхватываются без обновления самой программы.

**Поиск и списки видео каналов** берутся через публичные API
[Piped](https://github.com/TeamPiped/Piped) и
[Invidious](https://docs.invidious.io/) — все инстансы опрашиваются параллельно,
отвечает первый живой. Если все недоступны, есть откат на внутренний API YouTube
(InnerTube). Выбор качества показывает форматы оттуда же, а если и это недоступно —
предлагается стандартный список качеств (144p…4K), потому что для самой загрузки
yt-dlp всё равно достаточно ссылки и желаемого качества.

Размер APK больше обычного (~несколько десятков МБ) из-за упакованных Python и
ffmpeg. Собираются только ABI `arm64-v8a` и `armeabi-v7a` — они покрывают
практически все телефоны.

## Установка

APK собирается в GitHub Actions.

1. Открыть вкладку **Actions** в репозитории → workflow **Build APK** → последний
   зелёный запуск.
2. Скачать артефакт **YTdl-apk** и распаковать `YTdl.apk`.
3. На телефоне разрешить установку из неизвестных источников и установить APK.

Минимальная версия Android — 7.0 (API 24).

## Сборка локально

```bash
./gradlew assembleRelease
# app/build/outputs/apk/release/app-release.apk
```

Нужен Android SDK (compileSdk 35) и JDK 17.

## Подпись

В репозитории лежит `keystore/ytdl.jks` — тестовый ключ, чтобы APK из CI
устанавливался и обновлялся без переустановки. Для публичного распространения
замените его на свой и уберите пароли из `app/build.gradle.kts`.

## Замечание

Скачивание роликов противоречит условиям использования YouTube, кроме случаев,
когда правообладатель это разрешил или это допускает местное законодательство.
Проект предназначен для личного использования и собственного контента.
